# References

Store downloaded papers and other source documents for the report in this
folder. Use descriptive filenames, and keep the citation details with each
source: author(s), title, publication or website, year, DOI or URL, and access
date for web pages.

Only cite sources that have been checked and actually used in the report.
Use `../literature_matrix.csv` to track each source's method, workload,
assumptions, metrics, findings, limitations, and project relevance. Mark
details that have not been verified as requiring further extraction.
